# 🤖 Jarvis Voice Assistant

A Python-based voice assistant that listens for **"Jarvis"** and performs commands using voice.

### Features

* 🎙️ Speech recognition
* 🔊 Text-to-speech
* 🌐 Opens Google, YouTube, Instagram, Facebook & LinkedIn
* 🎵 Plays songs from `musicLibrary`
* 📰 Reads random news headlines
* 🤖 Uses Google Gemini for general questions
* 🛑 Voice command to shut down
